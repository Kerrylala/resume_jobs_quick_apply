# Resume Jobs AI 中文运行指南

## 第一次使用

Dashboard 会根据当前真实数据自动显示下一步，不读取旧缓存或旧报告
决定 Workflow。

1. **Upload Resume**：上传 PDF、DOCX 或 UTF-8 TXT。
2. **Review Profile**：检查系统提取的事实；可新增、编辑、删除、拒绝，
   确认无误后批准当前事实快照。
3. **Create Job Search**：保存目标职位、地点、级别、技能、排除条件、
   薪资偏好和数量限制。
4. **Find Jobs**：选择 Live Search、粘贴一个公开职位详情 URL，或运行
   localhost Offline Demo。
5. **Review Matches**：查看技术、经验、教育、地点、薪资、职业方向六个
   维度，以及证据、缺口和安全状态。
6. **Approve**：只批准希望继续的职位。
7. **Build Package**：确认最佳简历版本、历史答案、未知问题、敏感问题和
  预计完成率。
8. **Approve AI Fill / Start AI Fill Assistant**：选择 Chrome 扩展或可见的
   Local Browser Agent，然后打开对应申请页面。
9. **Review**：处理登录、验证码、MFA、新问题、敏感问题和附件。
10. **Submit**：最终提交必须由用户亲自完成。

## 搜索职位

### Live Search

在 **Settings -> Job Search Sources** 配置 SearXNG endpoint，保存并测试
连接。未配置或不可用时，按钮会显示明确原因，不会静默失败。

### 导入公开职位 URL

在 Job Search 页粘贴公开职位详情 URL，点击 **Import and Score**，并在
产品 Modal 中确认一次公开页面读取。系统会：

- 拒绝带账号密码的 URL；
- 拒绝远程 HTTP、内网地址、重定向和超大页面；
- 读取公开 HTML 元数据；
- 进入同一标准化、去重、评分和 Workflow 指纹流程。

这一步不会打开申请表、登录、上传简历或提交申请。

## Resume 与 Profile

- Resume Library 支持 Rename、Delete、Duplicate、Archive、Set Active、
  Import 和 Export。
- 上传时会进行本地解析，生成未确认的 Candidate Facts。
- 非活动 Resume 的分析只显示预览，不污染全局 Candidate Profile。
- 新事实不会覆盖用户已有事实。
- 每项事实记录来源、置信度、确认状态和最后使用时间。
- Profile 或 Resume 发生变化后，旧批准会失效，需要重新审核。

## Application Package

Package 绑定：

- 一个已批准且安全的职位；
- 最佳可用且已批准的 Resume Version；
- 用户确认过的历史答案；
- 未回答与敏感问题；
- 字段级来源、置信度和完成率；
- `REVIEW_ONLY` 与手工最终提交边界。

Package 不会自动打开网站、上传附件或提交。

## 浏览器扩展

Dashboard 点击 **Start AI Fill Assistant** 后，在对应职位页面打开扩展 popup。
扩展会从本地 Dashboard 同步已审核的安全字段，无需手工加载 Profile。开始前
产品会确认：

- 请求来自 Chrome 扩展；
- Dashboard 中当前选择的职位已经准备好；
- 当前页面 URL 与职位 URL 一致。

然后点击 **Fill known fields**。未知、低置信度、敏感、登录、CAPTCHA、MFA
和文件字段会停留给用户处理。最终 Submit 永远不会自动点击。

## 安全演示

```powershell
npm run demo
```

演示使用临时目录、合成资料和本地假申请表。建议首次使用先完成
演示，再配置真实数据。

## 停止运行

- 关闭 Windows Launcher 窗口；或
- 执行 `scripts\stop_dashboard_windows.ps1`；或
- 在终端启动时按 `Ctrl+C`。

停止服务不会删除数据。
