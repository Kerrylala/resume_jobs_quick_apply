# Resume Jobs AI 中文快速开始

## 准备环境

- Windows 11、macOS 或 Linux；
- Node.js 18 或更高版本；
- Chrome 或 Microsoft Edge；
- 本地可写磁盘目录。

首次安装在项目目录运行：

```powershell
npm install
npm run validate
```

Windows 用户之后可直接双击：

```text
dist\ResumeJobs Launcher.cmd
```

启动器会检查 Node.js、依赖、关键文件和 8767 端口，并打开
`http://127.0.0.1:8767`。macOS/Linux 使用 `npm start`。

## 第一次使用

按 Dashboard 显示的主操作依次完成：

1. 上传 PDF、DOCX 或 UTF-8 TXT 简历；
2. 审核自动提取的 Career Brain，修改错误并批准当前版本；
3. 在 Settings 配置可选 AI Provider；
4. 创建职位搜索目标，配置 SearXNG，或导入一个公开职位 URL；
5. 查看来源、查询原因、匹配优势和技能缺口；
6. 批准希望继续的职位；
7. 准备并审核 Application Package；
8. 批准安全填写，选择 Chrome Extension 或 Local Browser Agent；
9. 处理未填写、敏感、登录、CAPTCHA/MFA 和附件字段；
10. 检查全部内容后由本人最终提交，再回到 Dashboard 记录状态。

没有搜索结果不会锁死产品。可以修改搜索、重试、导入公开职位链接，
或运行只使用合成数据和 localhost 的 `npm run demo`。

## 安全边界

Resume Jobs 不会自动登录、绕过验证、上传简历、回答 EEO/敏感问题或
点击最终 Submit。不要在 Git 中提交 `data/*.json`、`documents/`、
`applications/`、`browser_profiles/`、`browser_sessions/`、`reports/`、
API key 或私人截图。

完整说明见 [中文用户指南](中文用户指南.md)，故障处理见
[中文故障排查](中文故障排查.md)。
