# Resume Jobs AI 中文安装指南

## 适用环境

- Windows 11、macOS 或 Linux
- Node.js 18 或更高版本
- Chrome 或 Microsoft Edge（浏览器辅助与本地演示需要）
- 本地磁盘空间约 500 MB（不包含用户自己的简历和长期运行数据）

## Windows 安装

1. 从 GitHub 下载源码并解压，或使用 Git 克隆仓库。
2. 安装 Node.js 18+，安装时保留“添加到 PATH”选项。
3. 在项目目录打开 PowerShell，执行：

```powershell
npm install
npm run validate
```

4. 双击 `dist\ResumeJobs Launcher.cmd`。
5. 启动器检查 Node.js、项目文件和 8767 端口，然后打开
   `http://127.0.0.1:8767`。

创建桌面快捷方式：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\create_resume_jobs_shortcut.ps1
```

## macOS / Linux 安装

```bash
npm install
npm run validate
npm start
```

浏览器打开 `http://127.0.0.1:8767`。

## 安装 Chrome 扩展

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `extensions/application_assistant`。
5. 固定 **Resume Jobs AI Fill Assistant** 图标。更新代码后需要在扩展页
   点击“重新加载”。

扩展不需要手工导入 Profile。用户点击 **Start AI Fill Assistant** 后，
Dashboard 会把当前职位已审核的 Package 和安全字段映射交给扩展。私有
Profile、简历内容、本地 Package、浏览器 profile 都不会进入 Git，也不会
作为网页可访问资源暴露。

## 可选 AI Provider

AI 不是搜索、评分和 Workflow 的必需条件。需要 AI 解释时，在
Dashboard 的 **Settings -> AI Provider** 中选择：

- Local OpenAI-compatible（例如 LM Studio）；
- OpenAI；
- Anthropic；
- 其他 HTTPS OpenAI-compatible 服务。

本地 provider 必须使用 localhost/loopback；远程 provider 必须使用
HTTPS。API key 只保存在被 Git 忽略的本地配置中，不会由 API 回传。

## 安装后验证

```powershell
npm test
npm run test:e2e
npm run test:launcher
```

这些测试使用合成数据、临时目录和 localhost，不读取正式职位、个人
Profile 或真实简历，也不会访问招聘网站。

## 卸载

1. 关闭启动器或执行 `scripts\stop_dashboard_windows.ps1`。
2. 在浏览器扩展页移除本地扩展。
3. 如不再需要数据，先手工备份 `data/`、`documents/resumes/` 和
   `applications/`，再由用户自行删除项目目录。

程序不会在卸载时自动删除任何用户数据。
