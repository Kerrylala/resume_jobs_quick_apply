# Resume Jobs AI 个人求职 Agent — 中文用户指南

Resume Jobs 是本地运行的个人 AI Job Application Agent。它帮助用户只
设置一次简历和求职目标，之后持续发现职位、解释匹配、准备材料并填写
已知安全字段。核心指标是已批准职位的 **Application Completion Rate**。

## 每日流程

1. **Home**：查看 Career Brain 状态、今日推荐、待处理申请和下一步。
2. **Resume**：上传、重命名、复制、归档、导入/导出或设置活动版本。
3. **Profile**：用普通表单审核身份、教育、经历、项目、技能和语言；
   高级 JSON 默认折叠。修改会创建 Draft，不会静默批准。
4. **Job Discovery**：查看系统生成的目标/相邻职位、地点、关键词和来源；
   运行搜索或导入用户确认的公开职位 URL。
5. **Job Matches**：查看来源、查询时间、发现原因、匹配分、优势、缺口和
   建议。职位分为当前结果、未见过、已见、已保存、已拒绝、已批准和已申请。
6. **Approve / Reject**：批准后才能准备申请；拒绝会保留可恢复历史。
7. **Application Package**：检查选择的简历/Profile 版本、求职信、面试题、
   STAR 故事、技能缺口、完成率和风险。
8. **AI Fill Assistant**：批准安全填写后选择 Chrome Extension（推荐）或
   Local Browser Agent（高级）。两者使用同一份已审核申请设置。
9. **Review skipped fields**：本人处理新问题、敏感问题、附件、登录和验证。
10. **Re-scan and learn**：只把用户明确批准的信息保存为 Career Brain Draft、
    Answer Memory 或不含候选人值的 Form Field Memory。
11. **Submit manually**：最终 Submit 只能由用户本人点击。

## 搜索和来源

中国机会显示为公司招聘官网、公开职位页、用户导入链接和辅助浏览；全球
机会显示为公司招聘官网、公开申请表、用户导入链接和辅助浏览。SearXNG
上游无结果时会显示真实诊断，不会伪造职位或多样性。

默认优先未见过、近期发布、新公司和相邻职位，并按配置延后重复、已拒绝、
已批准或已申请职位。历史记录不会被删除。

## 两种填写方式

- **Chrome Extension**：使用日常浏览器；需要从浏览器扩展页手工加载一次。
  Popup 只显示公司、职位、连接状态、字段统计和需审核项；技术信息在
  Advanced diagnostics。
- **Local Browser Agent**：打开可见的专用 Chrome/Edge 窗口和 Git 忽略的
  profile；保存已遮蔽截图和无候选人值的报告，支持 Retry 和 Re-scan。

两种方式都不会读取独立 Profile 副本，也不会自动上传或提交。

## Answer Memory

只有用户确认的答案才能复用。安全答案可以选择全局、国家、雇主、职位或
页面范围；工作许可、担保、薪资、法律声明、搬迁和通知期默认“不保存”，
每次都需要明确确认。密码、证件、财务、EEO、医疗、CAPTCHA、隐藏字段和
文件内容永不保存。

## 设置与重置

Settings 支持本地 OpenAI-compatible/LM Studio、OpenAI、Anthropic、
SearXNG 连接测试，以及 **Reset Local Data**。重置前产品会创建备份；它
不会删除仓库外文件或绕过确认。
