# Resume Jobs contributor handoff

Follow `AGENTS.md`. Start with `git status`, preserve user changes, reuse the
existing product architecture, run relevant tests, and keep local candidate
data out of Git.

For UI work, follow `docs/developer/UX_DESIGN_RULES.md`. Release UI must not use browser
native `alert`, `confirm`, or `prompt` dialogs.

Real-site access, login, resume upload, and final submission require explicit
user authorization.
